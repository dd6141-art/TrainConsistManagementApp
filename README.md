# TrainConsistManagementApp
UC1-A Java application that initializes an empty train consist using an ArrayList and displays the starting bogie count.  
UC2-A Java program demonstrating how to add, remove, and search for passenger bogies using ArrayList methods like add, remove, and contains.  
UC3-A Java program using HashSet to store unique bogie IDs and automatically prevent duplicate entries in the train consist.  
UC4-A Java program using LinkedList to manage the physical sequence of a train, including middle insertion and removing head/tail bogies.  
UC5-A Java program using LinkedHashSet to ensure every bogie in the train is unique while preserving the exact order in which they were attached.  
UC6-A Java program using HashMap to associate bogie names with their seating capacities using key-value pairs and entrySet iteration.
